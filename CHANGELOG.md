# Changelog

## v1.0.0-beta.1 — First public beta

This repository starts its public history with this release. Earlier internal builds, work reports, local test data, and transition notes are intentionally not part of the public history.

Highlights:

- Complete Chinese, English, and Japanese user interface and documentation entry points.
- Real MT4 quote/history bridge, data-quality validation, and calibrated research workflow.
- Verifiable AI model identity, unified local analysis sessions, news and specialist-research context.
- Demo and controlled live execution using shared audit and learning standards.
- AI parameter guidance with timestamps, rationale, user confirmation, versions, and rollback.
- User-editable position ceiling (default 2), MT4 account-capacity feedback, and margin reserve checks.
- Scheduled-event and abnormal-volatility monitoring, 15-minute specialist tracking, and operations centre.
- Local-first secret handling, pairing, emergency stop, disconnect protection, and execution receipts.
- Token usage summary for today, the latest seven reported days, and lifetime totals.

Known beta limitations:

- Windows and MetaTrader 4 are required for the full workflow.
- Broker-specific MT4 builds may require manual EA copy, compilation, and reattachment.
- Model and news availability depend on user-configured providers.
- Live execution remains locked by default and requires explicit local authorization.
