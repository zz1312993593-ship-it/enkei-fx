1 环境要求

项目要求
操作系统Windows 10 / 11（64 位）
Node.js18 或更高（启动脚本自动探测 PATH / 标准安装位置）
Python3.10+（仅 AI 终端使用；主面板不需要）
浏览器任意现代浏览器（Chrome / Edge 均可）
网络首次启动需联网安装依赖；新闻 / 云端 AI（如智谱）需联网；主面板可离线演示

2 首次启动

  1. 将项目文件夹完整复制到本机任意位置（建议路径不含中文或空格，如 D:\Enkei）。
  2. 双击 Start-Enkei.cmd。脚本自动完成：环境探测 → 依赖准备（首次联网拉取，可能数分钟）→ 启动自检 → 拉起面板。
  3. 看到「总览」页即启动成功。左侧导航共五个入口：总览 / AI 分析 / Demo / 模型 / 设置。
首次启动编译浏览器包可能需要 45 秒以上，属正常现象，请勿强制关闭窗口。

3 五个页面怎么用

页面作用要点
总览健康检查 / 本机服务 / 操作面板先看「启动自检」通过；行情桥、历史时钟、后台研究合格后才进 Demo。「在新页面打开完整说明书」就是这个页面右上角按钮。
AI 分析M5 / M15 时间段的研究与政策生成由 AI 终端统一分析体生成「多 / 空 / 观望」判断与理由，人类只做配置与复盘，无人工买卖入口。
Demo本地确定性行情 + 自动执行演练支持做多与做空；需先启动服务 → 验证连接 → 解除急停 → 输入配对码授权。
模型模型目录与路由配置（AI 终端内一并管理）展示已在 LibreChat / 智谱 / 本机 Ollama 验证的模型，可一键设为当前路由，不保存也不显示任何密钥。
设置风险参数、语言、时间区、AI 终端启停风险设置保存有防抖；「一键关闭 AI 终端」会等待进程真正退出，最多 15 秒，不会误报失败。

4 AI 终端配置

AI 终端是独立服务（默认 http://127.0.0.1:8710），在「设置 → AI 终端」里统一管理。

4.1 启动与停止

  • 启动 AI 终端：填写或确认终端地址后点「启动」，等待就绪。启动后状态行显示运行中，并轮询健康状态。
  • 一键关闭：点「停止」后进入「正在停止…」状态，前端会持续轮询 /health 直至进程退出（最多 15 秒）。若进程正常结束才会显示「已停止」；超时才提示取消失败——不会像旧版本那样刚点完就误报。

4.2 连通性测试与进度

  • 点「测试网关连通性」会先快速探测本地服务，再调用云端接口验证。
  • 测试期间显示百分比进度条（探测阶段封顶 85%，接口回调完成后跳到 100%），不会再出现“长时间无响应、像卡死”的情况。本地模型首次加载可能需要更久，属正常。

4.3 当前使用的模型

状态网格会显示「当前使用的模型」与「当前路由」两块卡片：例如 zhipu / glm-4.5-air、本地备用 llama3.2:3b 等，明确告诉你 AI 判断到底由哪个模型给出。

4.4 AI 判断展示

M5 / M15 提交后，「最新 AI 判断」区块会展示：多空方向（做多 / 做空 / 观望）、置信度、触发价与止损参考、判断理由、以及做出该判断所用的模型。AI 的建议全程可见，避免“只看到结果、看不到依据”的质疑。

5 模型与路由

5.1 三层模型来源

来源说明
LibreChat统一 AI 网关与模型管理，管理 API Key；圆衡只读取已配置的 Agent，不保存供应商密钥。
云端直连（如智谱）主路由：调用固定 temperature=0.2、max_tokens=384，适合短结构化政策判断。
本机 Ollama仅作离线备用（应急兜底），云端不可达时自动启用，避免阻塞。

5.2 选择 / 调用模型

  1. 「设置 → AI 终端 → 模型目录」列出所有已验证条目，标注 可用 / 未配置、价格档位、算力档位、推荐时间段。
  2. 每个可用条目带一个按钮：云端条目为「设为当前路由」，本地条目为「设为本地备用」。
  3. 点击后立即 PUT 保存并热生效，当前生效条目显示「当前路由 / 已生效」徽标。无需手抄模型 ID，也不用另开页面找领导要配置。
  4. 访问 Token 输入框已加随机名属性，浏览器不再弹出“是否保存此密码？”提示。

5.3 统一分析体

勾选「使用一个统一分析体处理 M5 与 M15」后，两个时间框共用同一 Agent，输出同一套 JSON 判断契约；时间框只决定输入提示中的职责与政策有效期。切换不同 AI 时不再出现“各自独立、上下文互不相通”的情况——统一分析体由 LibreChat 侧做会话调配。

6 新闻模块

  • 新闻区展示「市场简报」（本地规则摘要，明确标注非 AI 生成）、来源状态、最近条目。
  • 点「刷新」重新抓取；单个源失败只标红该源状态，不影响其它源与行情 / AI 分析。
  • 外网不可达时：来源状态显示失败原因，缓存过期时保留上次缓存并提示，不会误报“已刷新成功”。
  • 「手动注入」可补充专属消息（外网不可达时的替代手段）。
  • 源列表可在「设置 → AI 终端 → 新闻源」中替换（最多 12 个），非法项自动过滤，清空回退默认。

7 Demo 演练（做多 / 做空）

7.1 开通流程

  1. 进入 Demo 页，展开「启动 Demo 确认服务」并点击「启动」；控制中心确认服务显示「在线」后才具备执行能力。
  2. 「验证连接」跑通后解除急停（退出紧急状态）。
  3. 输入四段式配对码完成授权（由本机执行桥一次性生成，输入框已关闭浏览器“保存密码”弹窗）。
  4. 设置模型与做多 / 做空仓位参数并启用，自动执行即接管。

7.2 做多与做空

  • AI 判断为「做多」时走多头仓位流程；判断为「做空」时走空头仓位流程（缺口已补上，不再只有做多布局）。
  • 多空信号、入场 / 止损 / 目标价、每次仓位大小都在面板上展示。
  • 非人工断线会自动尝试恢复；人工急停绝不会自动解除，必须人工确认。

7.3 本机执行服务

若显示「本机执行服务暂不可达 / 自动恢复中」，请先在「总览 → 启动 Demo 确认服务」启动，确认状态为在线后再进 Demo；如持续自动恢复失败，见错误码 E302 与第 8、9 节。

8 错误码与故障处理

代码含义处理
E110本地组件准备中等待启动自检完成，不要强制关闭窗口。
E111组件安装失败联网后重新运行 Start-Enkei.cmd 自动补装。
E121启动自检不通过看启动诊断日志定位缺失项，修复后重跑。
E124只读后台服务守护失败检查端口占用与日志（见第 9 节）。
E140面板未在时限内就绪首次编译较慢时属正常；超久未就绪则重启面板。
E201行情桥不可用行情桥未启动 / 端口被占；按第 9 节收集日志。
E301Demo 配对未验证输入正确配对码并完成授权。
E302Demo 连接自动恢复中等待自动重连；持续失败则重启 Demo 确认服务。
上述任何异常都不影响浏览与本地研究；只有 Demo 自动执行与云端 AI 判断受影响。

9 如何恢复与收集日志

9.1 恢复

  • 面板异常：关闭所有 Enkei 窗口，重新双击 Start-Enkei.cmd。
  • 缓存 / 状态异常：删除项目根的 .enkei-runtime.json 与 enkei-*.log 后重启（会重新自检）。
  • AI 终端数据：删除 ai-terminal/data/ 下对应缓存（如 news/cache.json）后重启终端。
  • 干净基线：保留 Start-Enkei.cmd、launcher/、app/、lib/、ai-terminal/，其余生成物（.next/、node_modules/、.vinext/、日志）可安全删除后重新一键启动。
  • 重要：私有配置/（含本机 API 配置与模型文件）不属于开源包，恢复时请勿删除或外发。

9.2 日志位置（均在项目根目录）

文件内容
enkei-startup-diagnostic.log启动自检与错误码（每次启动覆盖）
enkei-panel-runtime.log面板运行时日志
enkei-ai-terminal-runtime.logAI 终端运行时日志
ai-terminal/temp_terminal_out.log / temp_terminal_err.logAI 终端独立输出

排查故障时请将上述文件一并打包提供；日志中不会包含任何 API 密钥。

10 常见问题

问题回答
主面板可以下单吗？不能。主面板只读，不含任何真实下单接口；只有 Demo 本地演练。
为什么 AI 测试那么久？云端调用受 max_tokens 限制已较快；本地 Ollama 首次加载模型可能几分钟。现在有进度条，可看到进行到哪一步。
为什么切页面会弹“用户名和密码”？旧版本输入框触发了浏览器保存密码提示，已改用随机表单名并关闭自动提示，不再弹出。
新闻刷新显示失败怎么办？确认外网可达后重试；单源失败只会标红该源。也可手动注入或用替换源。
我不知道现在用的是哪个模型？AI 终端状态网格的「当前使用的模型」卡片直接显示；AI 判断区块也会标注所用模型。
Demo 无法自动交易？确认「总览 → 启动 Demo 确认服务」已启动且状态为在线，完成配对授权并解除急停。
如何更换云端 / 本地模型？「设置 → AI 终端 → 模型目录」选中可用条目点「设为当前路由 / 设为本地备用」即热生效。
